# STANDING · 新任务先对 Skill（t1264u）

生效：2026-10-27 02:43 Asia/Shanghai  
用户钉：尝试新任务时，**先找合适的 Skill → 学习应用 → 再完成任务**。  
覆盖面（非穷尽）：团队分工/管理、写作、各类帖子/图片/文案生成、各类界面与交互、制作栈、运营玩法等。

## 0. 硬钉
- [ ] **禁裸干**：新任务、新平台、新体裁、新界面、新分工改动，开工前必须先完成 Skill 对仓/对库
- [ ] **禁空分析当交付**：搜到不等于应用；交付物是「已按 Skill 跑通的产物/合同/样」，不是侦察长文
- [ ] 零新订阅；禁付费栈除非用户另令
- [ ] 与既有站规冲突时：§26 选题闸 / PREPOST / 外发授权 / 本站合规优先；Skill 只改「怎么做」，不改「能不能发」

## 1. 最短链（默认）
```
新任务
  → 搜合适 Skill（本机 workflows / Cursor-managed / 开源·X·GitHub / 用户收藏与点名仓）
  → 选定 1 套主 Skill（可附 0–2 个参考；禁堆五个并行空读）
  → 读 SKILL.md + 必要 references；本地 vendor/装好依赖（可逆）
  → 冒烟：最小可验收一步（sheet / 草稿结构 / UI 一屏 / 合同模板一行）
  → 产线合同写明「采用 Skill 路径 + 验收」
  → 再做事（制作/发帖/改流程）
```

## 2. 谁负责
| 角色 | 动作 |
|------|------|

4. 公开 GitHub / X 教程（经侦察→落地闸）
