# 搬运线站规摘要（已消毒）

本目录是与 YouTube→B 站翻译搬运、口播时轴、去 AI 腔和制作质量相关的站规，路径已改为占位符。t 号保留。本对照任务（`TASK_1MIN_HOOK.md`）**禁止发布**，即使某些站规描述过「形态过审后可直发」。

## 对本任务最要紧的几条

1. **出处**：简介必须有原 YouTube 完整链接，并写明「本视频为 AI 技术搬运翻译」，不冒充原作者或官方。本任务原链是 https://www.youtube.com/watch?v=xKlUf-dw_Lw 。
2. **原声必须削尽**（后写覆盖前写）：早期站规曾允许「保留原声」或「压低约 -18dB 垫底」。用户在 t2809u / t2810u 亲定后，**原片原声必须去掉**，不是 duck；成片只留中文配音（grokko_sweet）+ 中文字幕；可薄叠无歌词 BGM。本对照任务的源成片已经是削尽原声的版本，精剪不得把原声带回来。
3. **第三人称 + 画面跟着口播走**：配音落在对应画面窗口内；不要为了填时长去拉语速；不要第一人称「我测试」。见 `STANDING_NARRATION_AV_SYNC_T188.md` 与 `skills/narration-av-sync`。
4. **去广告硬切**：长片已切掉课程硬广与片尾求订阅 CTA。精剪不要用未切广告的 YouTube 原片，也不要把广告段捞回来。
5. **画幅**：本对照任务只做 B 站向 **16:9**。抖音 9:16「YouTube 翻译精剪转抖音」线仍 HOLD，不要做竖屏。
6. **数字**：花费、行数、token、额度均为**原作者说法**，不得写成我方实测或官方数字。Fable 5.2 官方事实只使用 https://www.anthropic.com/claude-fable-and-mythos-5-2 已核要点，禁止外编跑分。
7. **钩子**：快节奏抓眼前 几秒要有效果/结果感，不要先念步骤清单。见 `STANDING_DRYGOODS_HOOK_FIRST_T1589.md`。精剪是截取中间关键部分，不是把长片缩成迷你版。
8. **SAMPLE ≠ 授发**：出片后停，交给所有者目视。不要登录平台、不要上传。
9. **去 AI 腔**：中文稿走 `de-ai-zh`；禁「赋能、闭环、打造、一站式、引领、开启新篇章」；禁止把 AGI 或人类水平意识写成结论。
10. **开工先对技能**：见 `STANDING_SKILL_FIRST.md`。质量条见 `STANDING_CRAFT_QUALITY.md`、`STANDING_PRODUCE_CHECKLIST.md`。封面用精剪真实帧，见 `oil-cover-agent`。
