# Steps

1. Read the pull table (`queue/artifacts/YYYY-MM-DD-x-bookmarks-pull-*.md` or routine equivalent) and `platforms/x/BOOKMARK_LEARN_CURSOR.md`. List **new** bookmarks only. If none → quiet close; do not ping user.
2. **Prioritize (t128u)**: rank before deep-dive — **prefer small accounts that suddenly blew up** (粉少却突然爆), **not only mega-accounts**. Primary: author followers <10k (then 10k–50k) whose single post engagement is abnormally high for that tier. Mega-account tutorials may yield methods but must not fill the priority queue alone.
3. For each kept post write the triad:
   - **Hook**: one-line hook (+ author / link / follower count + engagement snapshot)
   - **Learnable**: design / motion / copy / distribution / tool — actionable; no empty analysis; rhetoric exaggeration does not void the post (extract method; HOLD only dangerous derived lines)
   - **Role × action × acceptance**: concrete owner, verb, checkable done. For an adopted, producible row, also write the successor role, unique owner, deadline (Asia/Shanghai), work type (tutorial / share video / not-applicable), landing path, and authorization stop. Distinguish 候选 / 已采用 / 已交接 / 已完成；a candidate list is not a finished tutorial.
4. Build a shortlist ≥5 "ready to dispatch" when volume allows. Mark HOLD / TOOLS / already-covered explicitly. Note which rows were 粉少却突然爆 picks. Same-event multi-platform references may be reused; do not limit benchmarks to a single X post.
5. Drop draft at `queue/artifacts/YYYY-MM-DD-x-bookmark-learn-*.md`. Do not post or DM from this skill.
6. Hand adopted, producible rows to the named successor (captain dispatch / FILE_FIRST). Closeout requires the successor, deadline, and tutorial/video path (or a documented「不适用教程」plus a verifiable result). Inbox notes and file-only edits are not closeout; mark「已交接/待作品」until the work lands. Non-production adoptions and HOLD do not force a video. **Do not auto-report the user from this skill.**
7. After the run: note misses in `team/evolution_log.md`. If steps drifted, propose a skill-body patch; human approves any `UpdateSkill`.

- Every kept post has all three triad fields
- Priority order applied (粉少却突然爆小号 before mega-account-only filler)
