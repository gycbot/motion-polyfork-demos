# Concept diagram → original premium tutorial pack (SOP)

Golden sample: a five-column content-production loop (collect → filter → generate → distribute → review) rebuilt from scratch as one persistent picture. Owner correction: flat white was clean but not premium enough; default now is a web page with glassmorphism + flowing light, rendered frame-by-frame to video.

## 0. Rights gate
- Never repost source video/pixels/logos; learn structure and rhythm only, redraw everything.
- No official logos, characters, invented product claims/numbers, or income promises.

## 1. Lock before production
- ≥3 references, ≥2 platforms, real visible likes/saves + fetch time in BRIEF.md (include premium web/UI refs: glass, flowing gradients). Never fake engagement; say what wasn't actually viewed.
- Verified skills first (motion-house-style, surface-web-craft-kit, scout-video-repurpose, viral-copy-zh, de-ai-zh); TECH_SELECT.md table: refs | skill + verified scope | component | proof | diff. New tries ≤2.
- Seven dims each ≥8 before full render: 2s hook, 360px phone readability, motion, change every 2–4s, composition, brand cleanliness, premium finish.

## 2. Build as a web page
- Glass cards (backdrop-filter, translucent edge, highlight), low-saturation flowing light/fluid background, light flowing along paths with dots at constant arc-length speed, blur-slide text (opacity/blur/y same progress, Chinese split by meaning).
- Restraint: no large neon, no full blue-purple frames, no bounce, black frames, fine print, page numbers.
- Deterministic time: expose `window.__setTime(t)` (or embed in Remotion) and capture frame-by-frame with Playwright/Remotion; never real-time screen record.
- Layouts from one page: 16:9 overview; 9:16 vertical relayout (all stages persistent, current expanded); 3:4 carousel cards.
- Keyframes (open/mid/end + 360px crops) and a ≤4s motion proof → owner/style check → only then full render.

## 3. Per-platform package
- 16:9 video, 9:16 video (add legal BGM or VO before posting), 3:4 carousel (cover + one idea per card), COPY.md (titles, platform bodies, hook, hashtags; de-ai-zh).

## 4. Extensions
- Web-page showcase: ship the page itself, interactive (hover/click a stage to expand).
- Architecture video: swap stages for system modules; keep the loop-back path as the compounding beat.
- Sellable one-import pack: page/Remotion source + fonts + props JSON (stages, colors, copy) + README (install, edit props, render) + preview mp4 + carousel templates in one zip that renders after install with only props edited. Pricing/channel need owner sign-off.

## 5. QA and handoff
- ffprobe, full decode, no ≥0.3s empty mid-frames, md5 list, HANDOFF.md with deviations/risks.
- Deliver as SAMPLE. Hand to platform operators only on explicit go; relay any pause instantly. Operators run their pre-post survival check.
