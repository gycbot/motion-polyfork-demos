# 预览交付 · 切段 / 私密 B 站（preview-deliver-split）

叠：站规 `STANDING_LONG_SAMPLE_BILI_PRIVATE_T2685` · SAMPLE≠授发

## 规则
1. **≤30s**：可聊天直传预览（另有点名除外）。
2. **>30s**：不要只丢一个超大单文件当唯一交付。二选一或组合：  
   - **切两段**（叙事拐点切开，两段体量都可打开）  
   - **B 站 · 仅自己可见**，回传 BV/链（禁公开/粉丝可见/推推荐）
3. 用户明确「切成两个给我看」→ 当日优先切段，不擅自改去公开台。
4. SAMPLE / 预览 **≠** 授发；公开须另令。
5. 切点选在**句子与场景完整处**（如对话问完、巡逻再起前），禁止砍在单词中间。

## 切段实务
- 命名：`preview-vN-part1.mp4` / `part2.mp4`（或上/下集中文）。
- 附一句：上半讲到哪、下半从哪起。
- 两段都做 size 目测（聊天友好）；音频淡入淡出可选，但不要改剧情内容。

## 私密 B 站实务
- 可见性锁「仅自己可见」；截图或文案确认。
- 合同/运营派单按队内 bili private 流程；制作岗不自作主张公开。

## 禁
- 用「文件太大」为由不交预览
- 未令上传公开稿
- 切段后丢掉全片母带（母带仍留 final/）
