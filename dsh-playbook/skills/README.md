# 本包收录的技能

每个子目录一个 `SKILL.md`（WorkBuddy 要求这个精确文件名）。部分带 `steps.yaml`。路径相对于仓库根目录 `skills/<name>/`。

## 对照任务建议启用

| 目录 | 角色 |
|------|------|
| `skill-first-task` | 开工质量门：对标、已验证技能、观感标准 |
| `user-taste-transfer` | 主人口味与纠正迁移 |
| `de-ai-zh` | 去中文 AI 腔（入口 skill；上游全文未捆绑） |
| `dsh-executor` | 执行质量条与交付物合同（亦在 `dsh_system/skills/dsh-executor/`） |
| `scout-video-repurpose` | 把已有成片改编为新平台/新节奏的资产 |
| `narration-av-sync` | 画面跟口播，禁止整段拉语速 |
| `viral-copy-zh` | 中文钩子与标题 |
| `oil-cover-agent` | 从成片真实帧做证据封面 |
| `preview-deliver-split` | 长预览切段；SAMPLE ≠ 授发 |
| `motion-house-style` | 运动密度与禁 AI 套版 |
| `x-bookmark-drygoods-video` | 干货搬运/二创（相关） |
