# X bookmark -> drygoods short video

## When
Growth-line shorts whose raw material is an X bookmark (workflow, skill demo, checklist). Not for empty slogan cards, pure aesthetic vibe films, or referral-only posts.

## Hard gates
- Audience can name **>=3 executable steps** after watching.
- **Legal BGM** required before handoff; no silent empty text cards.
- **No earnings / follower / money promises** in hook, title, cover, or voiceover.
- Sensitive bans still apply (politics, porn, privacy, contraband).

## Pipeline
1. **Source**: Keep bookmark URL or id. Prefer small accounts that suddenly spiked; skip mega-account-only learning.
2. **Deep-split**: Reuse the upstream `x-bookmark-learn-triad` record when it exists (do not re-pull bookmarks or redo the research). Hook -> learnable points -> role x action x acceptance (triad). Drop posts with no teachable steps.
3. **Translate / rewrite**: Target-language, human tone, demo-ready. Strip hype that cannot be shown on screen.
4. **Hook-first (first 3-5s)**: Lead with exaggerated *effect* (time saved, before/after, class jump, conflict). Label the rhetoric pattern used (emotion word, persona, number contrast, suspense, anti-common-sense, numbered list, etc.) and cite >=1 source bookmark. **Do not** open on a step list.
5. **Body**: After the hook, >=3 visible demo steps. Each step needs highlight (label / zoom / motion). Low density = revise.
6. **Cover**: Follow the current cover router: default `oil-cover-agent` (referral/neitui posters do not use oil). A real evidence frame may be redesigned as the cover—do not ban evidence frames, and do not ship a plain unredesigned grab. Independent design - large hook text (<=10 chars main), clear hierarchy, contrast/texture. Cite the exact oil or specialist skill path and the step/component used.
7. **BGM**: Only cleared / licensed / platform-safe tracks; note file or id in handoff.
8. **Pre-quality gate**: Before burning render/VO quota, fill the start-gate three items (≥3 refined multi-platform high-like/high-save references, a verified skill path, and a quality bar written against those references) and align keyframes or sample frames to that bar. The producer itself enforces hook, density, and no-earnings-claims, plus platform and outbound limits; do not wake the STOP content-review or compliance roles. Publish only with CADENCE GO / an equivalent captain short-window GO (T2751) and a pre-publish survival check. SAMPLE≠授发.
9. **Per-platform pack**: Same raw OK, but each end must change >=2 of: hook VO/title, demo path/case, pacing, native packaging. **Forbid** same script/shots with only color or aspect retune. Default: win one end first, then adapt.

## Handoff fields (minimum)
- Source bookmark URL/id + rhetoric pattern label
- Effect hook line (3-5s)
- Three steps the viewer takes away
- Cover note (evidence frame may be redesigned; not a plain unredesigned grab) + oil/specialist skill path
- BGM note
- Target platform(s) and explicit cross-end diffs if multi-posting
- Start-gate three items (or inherited bar + this-time diff) and the keyframe/sample proof path

## Out of scope
- Buying reach, fake metrics, or undeclared AI watermark abuse
- Paying APIs / new platform logins without owner approval
- Rewriting frozen vibe aesthetic series rules
