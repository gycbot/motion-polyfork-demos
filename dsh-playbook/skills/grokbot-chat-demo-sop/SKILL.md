# Grok Bot chat-demo SOP (fixed flow · multi-media · interactive open · logic loop)

## Goal
Locked Remotion chat-UI demo for tutorials showing Grok Bot working. Same skeleton for web / image / video.
t2622: **link-open must feel interactive**; **video returns must visibly play embedded**.
t2624: **each deliverable = user-ask → bot-make → result-show**; main request ends at its result; **ban orphan showcase**.

Standing: `standing/STANDING_GROKBOT_CHAT_DEMO_SOP_T2619.md`  
Gold web SAMPLE: `…/chat-sample-t2613.mp4` · iterate `chat-sample-t2622.mp4` (open+embed) → **`chat-sample-t2624.mp4` (logic loop)**  
Also: `motion-house-style`, `user-taste-transfer`, `remotion-multimedia` when embedding video.

## Fixed beats
32–42s (was 28–36; stretch OK for multi-loop) · 1080×1920 · 2–4s new info · real App UI kit · grey/black/white.

1 Boot → 2 user type/send → 3 bot confirm → 4 short confirm → 5 progress → 6 artifact return → 7 accept → 8 delivery → 9 fullscreen open → 10 **optional next loop** (new user ask → make → result) → 11 CTA.

### Logic loop (t2624) — required
- **Main request → direct result**: after pill/open (or image/video deliver) for the *primary* ask, **stop that segment**; do **not** stuff another medium with no user ask (“同波又渲了…” banned).
- **Every later deliverable** needs its own: **user demand** (or bot short offer + user nod) → **bot short confirm + progress** → **result** (pill open / embedded play / fullscreen).
- Showcase strips / extra deed pills: only after user ask or bot「还要同波页吗」→ user yes.
- Keep t2622 open interaction + OffthreadVideo embed quality; do not trade logic for hard cuts or cover-stills.

### Web open (beats 8→9) — required interaction
1. Pill **press** (scale/highlight; optional tap ripple, no neon)
2. **Expand/morph** from pill into phone browser chrome; address bar shows full live URL
3. Brief skeleton/top progress → real page content; optional **scroll peek**
4. Ban hard-cut to fullscreen still with no press/chrome

### Video return (own loop, not orphan)
- New user bubble asking for vertical/short film (口语、de-ai)
- Bot confirm + short progress (分镜→渲染→配字)
- `<OffthreadVideo>` / `<Video>` playing in mini player → morph fullscreen
- Ban cover-still labeled “视频”; ban abstract color blocks; ban inserting video with no prior user ask

### Image path
Fullscreen image after press on image card; same no-hard-cut preference; same demand→make→show loop.

## Hard bans
Concept mock chat; poor Grokko models; disclaimer microcopy; fake domains; third-party sites as ours; empty “做好了”; income-teardown VO; **orphan showcase / “同波又…” without demand**.

## Output
SAMPLE mp4 + stills + contact + RECEIPT; SAMPLE≠授发.
